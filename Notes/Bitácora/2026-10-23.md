No encontré mucha información sobre la selección del DELAY_FACTOR para la diferencia en la tesis de Julián, y tampoco sobre la selección del inicio de la meseta para estimar la zona válida para la FFT.

Tengo un script para promediar muchas realizaciones sobre la metrica que se obtiene mediante autocorrelación de S&C, para STF y LTF a diferentes SNR y en diferentes canales. 

**OBSERVACIÓN**: Dejé de usar el promedio y analicé 7 muestras con el mismo delay factor para las diferencias. Observé que para STF esta diferencia varía muchisimo menos que para LTF. Hice pruebas sin ruido para confirmar la hipotesis: la variación de la métrica de diferencias entre STF y LTF en un canal sin ruido es nula debido a que STF y LTF son símbolos conocidos y repetidos para todo el ensamble. Sin embargo el payload es un proceso estocástico, por lo que en la métrica de diferencias entre LTF y payload existe mayor variación. Así, la única fuente de variación para las diferencias entre STF y LTF es el canal.

Canal AWGN, SNR = 20 dB: 
	Varianza STF = 0.00574
	Varianza LTF = 0.19725

Ventajas de usar STF sobre LTF:
- Menor varianza.
- Pico de diferencias de mayor amplitud.

Otra observación del experimento anterior es que puedo usar dos métodos para determinar un punto robusto y muy cercano al punto inicial de los símbolos:
1. Cuando la métrica de autocorrelación está sobre la meseta, la diferencia se mantiene cercana a 0, por lo que puedo detectar cuando ésta supere un umbral negativo. Sería bueno añadir el filtro de mayoría para descartar falsos positivos.
2. Usar un úmbral arbitrario y previamente calculado para un factor de delay específico que represente el valor mínimo de la diferencia sobre toda la señal y restar un factor para controlar la robustez. Habría que analizar cada métrica de diferencia para decidir cuál es la mejor opción
